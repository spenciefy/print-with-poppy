# Social preview animation

Eight-second, silent 1200 × 630 H.264 loop using the original dense yellow, orange and red poppy artwork. Three bordered prints are already on the tabletop at the opening. Five more are gently laid over them, with short movement, rotation and settling shadows. No text or flowers falling. The added layers fade back to the original pile at the end for a loop.

From this directory:

```sh
npm ci
npm run render
npm run poster
```

The MP4 is served as `og:video`; the settled frame is the `og:image` fallback. Sharing-app support varies. The main app has no Remotion runtime dependency.
